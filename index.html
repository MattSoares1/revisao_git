⌨️ Atalhos do VS Code

Principais teclas de atalho para facilitar sua programação

Windows

📁 Arquivos

Novo arquivo Ctrl + N
Abrir arquivo Ctrl + O
Salvar arquivo Ctrl + S
Salvar como Ctrl + Shift + S
Fechar arquivo Ctrl + W

✏️ Edição

Desfazer Ctrl + Z
Refazer Ctrl + Y
Copiar linha Shift + Alt + ↓
Mover linha para cima Alt + ↑
Mover linha para baixo Alt + ↓
Comentar linha Ctrl + /

🔎 Pesquisa

Pesquisar no arquivo Ctrl + F
Substituir Ctrl + H
Pesquisar em todos os arquivos Ctrl + Shift + F
Ir para linha Ctrl + G

💻 VS Code

Terminal integrado Ctrl + `
Paleta de comandos Ctrl + Shift + P
Explorador de arquivos Ctrl + Shift + E
Extensões Ctrl + Shift + X
Formatar documento Shift + Alt + F
Página criada para estudo de HTML e CSS
